# HEARTWOOD
"Heartwood is the older, harder, and dead central core of a tree trunk. It no longer conducts water or sap, but it provides heavy structural support and resists decay better than the outer layers."

This project was made and tested in Gamemaker LTS 2026.0.0 on Arch Linux.
